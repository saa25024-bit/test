GitHub Pages公開時の重要ステップ

Google認証を自分のGitHub Pagesドメインで有効化するには、Firebase Console側での「承認済みドメイン」追加が必要です。

1. Firebase Console設定（OAuthドメイン許可）

  1. Firebase Console にログイン
  2. プロジェクト task-53f0a を選択
  3. 左メニュー「Authentication」→「Settings」タブ→「承認済みドメイン (Authorized domains)」を開く
  4. 「ドメインの追加」をクリックし、GitHub PagesのURL（例: username.github.io）を追加してください

2. GitHub Pages 公開手順

  1. このファイルを index.html という名前で保存
  2. GitHubで新しいリポジトリを作成（例: kakeibo-app）
  3. index.html をリポジトリにプッシュ
  4. リポジトリの「Settings」→「Pages」を開き、Branchを main に設定して保存
